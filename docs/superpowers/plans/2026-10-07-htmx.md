# htmx Report Tabs and Capacity Fragments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the report one section at a time as tabs, and make the capacity
forms update in place with live totals, using htmx 4.0.0. Remove the `report`
command and add "Save as default" in its place.

**Architecture:** The server keeps rendering HTML. Each swappable piece has
exactly one render function. The full page is assembled from those functions,
and small fragment routes return a single piece. htmx 4 swaps the pieces. All
scripts are served files, and a `script-src 'self'` Content-Security-Policy
blocks any inline script.

**Tech Stack:** Python 3, Flask, DuckDB, htmx 4.0.0 (vendored), uPlot 1.6.31
(vendored).

**Spec:** `docs/superpowers/specs/2026-10-07-htmx-design.md`. Read it before
starting. Issue: #38. Branch: `feat/38-htmx`.

## Global Constraints

- Gate: `sh tests/run.sh` must pass after every task. It runs ruff 0.16.8,
  shellcheck, `tests/no-leaks.sh` and every `test_*.py`.
- Run one test file: `uv run --isolated --with-requirements requirements.txt python <file>`.
- Tests are plain `assert` functions named `test_*` in the existing files. Each
  file ends with a `__main__` runner. Add tests to existing files, so
  `tests/run.sh` and `test_checks.py` need no new names.
- Line length 100. Full imports, never relative ones.
- No new Python dependencies. `requirements.in` stays `duckdb` and `flask`.
- Fixtures are synthetic. No employer names, ticket keys or hosts: the leak
  guard fails the gate.
- No em dashes or double dashes in prose, comments, docstrings or commit messages.
- htmx 4.0.0. `vendor/htmx.min.js` SHA-256 is
  `e484d9171a9db30a39c8f16e3d709d4137f3211c659f8e6125816635033d593f`.
- Content-Security-Policy:
  `script-src 'self'; object-src 'none'; base-uri 'none'`.
- No inline executable `<script>` on any served page. The
  `<script type="application/json" class="plot-data">` data islands stay.
- Fragment routes never write to the database and never take `project.lock`.
- htmx 4 facts this plan relies on, all checked in the 4.0.0 source:
  - A POST from an element inside a form sends the whole form.
  - A clicked button's own `name`/`value` is sent only on a form submit event,
    so the Add and Remove buttons encode their intent in the URL.
  - `hx-swap-oob` finds its target with `CSS.escape`d ids.
  - Every response swaps except 204 and 304.
  - The settle event is `htmx:after:settle`.
  - History restore re-fetches the page URL with an
    `HX-History-Restore-Request: true` header.
- Commit after each task with a Conventional Commit naming `(#38)`, ending with
  the trailer line:
  `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`

## Review Focus

1. **Repeated filters across tab switches.** `component=A&component=B` must
   keep both values after switching tabs (Task 3, test
   `test_tabs_carry_every_filter_value`).
2. **Member ids that need escaping in the Remove URL.** An id like
   `jira:a b&c` must remove exactly that member (Task 5, test
   `test_remove_url_escapes_the_member_id`).
3. **A tampered or invalid `payload` sent to a fragment route.** It must return
   a message in the fragment, never a 500 (Tasks 5 and 6, tests
   `test_members_rejects_an_invalid_payload_in_place` and
   `test_totals_reports_an_invalid_payload_in_place`).
4. **Remove with JavaScript disabled.** The button submits the whole plan form
   to the plan URL, which must drop the member (Task 5, test
   `test_remove_without_javascript_drops_the_member`).
5. **The back button.** htmx re-fetches `/<slug>/?section=flow` with
   `HX-History-Restore-Request: true`. The response must be the full page
   (Task 3, test `test_history_restore_gets_the_full_page`).

   readable without it, and every chart keeps its server-drawn SVG. */
(function () {
  function sortable(root) {
    root.querySelectorAll('table.sortable').forEach(function (table) {
      var head = table.tHead.rows[0];
      Array.prototype.forEach.call(head.cells, function (cell, index) {
        function apply() {
          var rows = Array.prototype.slice.call(table.tBodies[0].rows);
          var descending = cell.getAttribute('aria-sort') !== 'descending';
          var numeric = rows.every(function (row) {
            var text = row.cells[index].textContent.trim();
            return text === '' || !isNaN(Number(text));
          });
          rows.sort(function (a, b) {
            var x = a.cells[index].textContent.trim();
            var y = b.cells[index].textContent.trim();
            if (numeric) { return (Number(x) - Number(y)) * (descending ? -1 : 1); }
            return x.localeCompare(y) * (descending ? -1 : 1);
          });
          Array.prototype.forEach.call(head.cells, function (other) {
            other.setAttribute('aria-sort', 'none');
          });
          cell.setAttribute('aria-sort', descending ? 'descending' : 'ascending');
          rows.forEach(function (row) { table.tBodies[0].appendChild(row); });
        }
        cell.addEventListener('click', apply);
        cell.addEventListener('keydown', function (event) {
          if (event.key === 'Enter' || event.key === ' ') { event.preventDefault(); apply(); }
        });
      });
    });
  }

  function plots(root) {
    if (typeof uPlot === 'undefined') { return; }
    var styles = getComputedStyle(document.documentElement);
    function token(name, fallback) {
      var v = styles.getPropertyValue(name);
      return v ? v.trim() : fallback;
    }
    root.querySelectorAll('.plot').forEach(function (box) {
      /* PASTE the body of PLOT_SCRIPT's forEach callback here unchanged, from
         `var island = box.querySelector('script.plot-data');` through
         `window.addEventListener('resize', ...);`. */
    });
  }

  /* ponytail: each swap adds resize listeners for charts that a later swap
     removes. A few per tab switch, bounded by how long one tab stays open. */
  function init(root) { sortable(root); plots(root); }

  init(document);
  document.addEventListener('htmx:after:settle', function (event) { init(event.target); });
